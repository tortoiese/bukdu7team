# ENTRY

매대 태그를 스캔하면 로그인 없이 그 순간의 구매 의도가 기록되고, 고객이 어느 나라로 이동하든 그 기록이 따라가 현지 재고·채널로 연결되는 서비스.

## 로컬 실행

```bash
npm install
npm --prefix web install
npm run dev
```

`npm run dev`가 웹(5173)·API(8080)를 동시에 띄운다. 웹 첫 화면(`/`)에서 `/api/v1/health` 응답을 확인할 수 있다.
