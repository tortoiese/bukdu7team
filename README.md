# ENTRY

**매대 태그를 스캔하면, 로그인 없이 그 순간의 구매 의도가 기록됩니다.**
고객이 어느 나라로 이동하든 — 그 기록은 현지 재고와 채널로 따라갑니다.

**🔗 지금 바로 체험하기 → [entrypassport.1.201.116.98.sslip.io](https://entrypassport.1.201.116.98.sslip.io/)**
설치나 로그인 없이 모바일 웹으로 바로 열립니다.

---

## 문제

오프라인 매장은 고객이 무엇을 집어 들었다 내려놓았는지 알 방법이 없습니다. 매장 방문객의 대다수는 구매 없이 나가고, 이들에 대한 데이터는 어디에도 남지 않습니다. 팝업스토어는 수억 원의 경험이 철수와 동시에 사라지고, 여행객이 서울에서 본 제품을 홍콩·도쿄로 돌아가서 사고 싶어도 그 관심을 이어줄 채널이 없습니다.

## 해결 방법

**매대 태그 스캔 한 번으로 시작되는, 로그인 없는 익명 세션.**

- **무마찰 스캔** — QR 스캔만으로 제품 정보·제작 배경·실물 재고를 즉시 확인, 아카이브에 저장
- **팝업 패스포트** — 구역을 방문할 때마다 검인(스탬프)이 쌓이고, 더 많이 체험할수록 더 높은 열람 권한이 열립니다 (보상은 할인이 아니라 **접근 권한**)
- **국경 이전** — 고객이 시장을 이동하면, 저장했던 제품이 현지 재고와 채널로 자동 연결됩니다
- **운영자 대시보드** — 브랜드는 어떤 제품이 관심을 받고도 팔리지 않는지, 어느 구역이 체류·저장으로 이어지는지 실시간으로 확인합니다
- **AI는 장식이 아닙니다** — 의도 신호 분석, 방문 리캡 요약, 국경 이전 메시지, 어드바이저 브리핑까지 다섯 지점에서 실제로 호출되며, 실패해도 화면은 항상 규칙 기반으로 렌더링됩니다

## 개발자를 위한 안내

로컬에서 직접 실행하려면:

```bash
npm install
npm --prefix web install
npm run dev
```

`npm run dev`가 웹(5173)·API(8080)를 동시에 띄웁니다. 웹 첫 화면(`/`)에서 `/api/v1/health` 응답을 확인할 수 있습니다.

배포·인프라 구성은 [`BUILD_STEPS.md`](./BUILD_STEPS.md), 코딩·협업 규칙은 [`CLAUDE.md`](./CLAUDE.md)를 참고하세요.
