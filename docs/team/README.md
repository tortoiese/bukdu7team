# 팀원 참여 안내

팀원별 담당과 소개는 이 폴더에 한 명당 한 파일로 기록합니다. GitHub Contributors에는 이슈 댓글이 아니라 실제 커밋을 기준으로 기여 기록이 표시되므로, 각 팀원이 자신의 파일을 직접 추가하는 방식을 권장합니다.

## 작성 방법

1. GitHub 저장소에서 `Add file` → `Create new file`을 선택합니다.
2. 파일명을 `docs/team/이름.md`로 입력합니다.
3. 이름, 담당 파트, 한 줄 소개를 작성합니다.
4. `Commit changes`를 누릅니다.
5. `Create a new branch for this commit and start a pull request`를 선택합니다.
6. PR을 만들고 팀원 검토 후 병합합니다.

`main` 브랜치에는 직접 커밋하지 않습니다.

## 작성 양식

```markdown
# 홍길동

- 담당: 프론트엔드
- 한 줄 소개: ENTRY의 모바일 화면과 사용자 경험을 담당합니다.
```

## 협업 기록 남기기

- 팀원 파일 커밋: GitHub Contributors에 실제 기여 기록을 남깁니다.
- 이슈와 댓글: 의사결정, 질문, 진행 과정을 남깁니다.

두 방식을 함께 사용하면 코드 기여와 협업 과정이 모두 기록됩니다.
