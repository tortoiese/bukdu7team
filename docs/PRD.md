## 1. 문제 정의

온라인 스토어는 고객이 장바구니에 담았다 뺀 상품까지 전부 기록한다. 반면 오프라인 매장은 고객이 무엇을 집어 들었다 내려놓았는지 알 방법이 없다. 매장 방문객의 대다수는 구매 없이 나가지만, 이들에 대한 데이터는 존재하지 않는다.

현재 오프라인 데이터 수집 방식은 모두 한계가 명확하다.

| 방식 | 한계 |
| --- | --- |
| CCTV 카운팅 | 인프라 비용이 크고 개별 관심도 파악 불가 |
| 카드 결제 데이터 | 구매자만 포착, 사후적 데이터 |
| 비콘 | 정밀도를 높일수록 비용과 유지보수 부담 급증 |

그 결과 세 가지 손실이 발생한다.

1. **미구매 방문의 소실** — 고민하다 나간 고객의 관심 대상이 어디에도 남지 않는다
2. **채널 단절** — 온라인 탐색 이력이 매장 문턱에서 끊기고, 매장 상담 내용도 온라인에 남지 않는다
3. **팝업의 일회성** — 수억 원의 경험이 철수와 동시에 소멸하고 방문객 명단이 남지 않는다

동시에 고객 측에서도 문제가 있다. 매장에서 가격표와 태그를 촬영해 나가는 행동이 일상화되어 있는데, 브랜드는 이를 이탈로만 취급해왔다. 촬영은 막을 대상이 아니라 이미 발생하고 있는 관심 신호다.

## 2. 해결 방향

**몰래 찍히던 태그를, 브랜드가 먼저 스캔하도록 내미는 접점으로 전환한다.**

```
[매장 태그 스캔] → [개인 아카이브] → [어드바이저 상담 / 구매]
                        ↕
                  [팝업 패스포트] → [초대 · 선공개]
```

두 축은 별개 기능이 아니라 하나의 계정 위에 쌓이는 단일 타임라인이다.

## 3. 타겟 사용자

### 주 사용자

**29세, 서울 거주, 직장인**
브랜드를 인지하고 있으며 구매 의향이 있으나 즉시 결정하지 못하는 상태. 매장에서 제품을 확인한 뒤 온라인에서 다시 검색하고, 며칠에서 몇 주 뒤 구매한다. 매장에서 태그를 촬영한 경험이 있다.

핵심 니즈

- 매장에서 본 제품을 나중에 다시 찾고 싶다
- 이 제품이 나에게 맞는지 확신을 얻고 싶다
- 직원에게 붙잡히지 않고 편하게 둘러보고 싶다

### 부 사용자

**매장 세일즈 어드바이저**
고객이 무엇에 관심 있는지 대화를 시작하기 전까지 알 수 없다. 응대 타이밍을 잡기 어렵다.

**브랜드 리테일 운영 담당자**
매장별 매출은 알지만 어떤 제품이 관심을 받고도 팔리지 않는지는 모른다.

## 4. 설계 원칙

이 프로젝트가 럭셔리 브랜드 맥락에서 성립하기 위한 가드레일이다. 기능 논의 시 이 원칙과 충돌하면 기능을 수정한다.

| 원칙 | 내용 |
| --- | --- |
| 가격 경쟁 프레임 배제 | 최저가, 할인율, 쿠폰, 가격 인하 알림을 노출하지 않는다. 고객을 붙잡는 수단은 가격이 아니라 정보와 확신이다 |
| 마찰 최소화 | 첫 스캔에 로그인을 요구하지 않는다. 가치를 먼저 보여주고 계정을 나중에 연결한다 |
| 능동 기록만 수집 | 사용자가 직접 스캔한 행동만 기록한다. 배경 위치 추적과 상시 동선 수집은 하지 않는다 |
| 감시가 아닌 기억 | 고객 화면의 언어는 추천과 분석이 아니라 기록과 정리에 가깝게 유지한다 |
| 설명 가능한 제안 | 무언가를 제안할 때 근거를 함께 제시한다. 근거 없는 자동 추천은 브랜드 신뢰를 훼손한다 |

## 5. 기능 명세

### F1. 무마찰 스캔 · 저장 (P0)

매대 태그의 QR 또는 NFC를 스캔하면 앱 설치와 로그인 없이 모바일 웹으로 진입하고, 해당 제품이 즉시 개인 아카이브에 저장된다.

- 익명 세션 토큰 기반으로 먼저 저장
- 계정 연결은 이후 단계에서 유도
- 저장 완료까지 3초 이내를 목표로 한다

**스캔 화면 구성 요소**

| 영역 | 내용 |
| --- | --- |
| 제품 기본 정보 | 명칭, 소재, 사이즈, 무게, 수납 사양 |
| 제작 배경 | 디자이너 노트, 제작 과정, 컬렉션 맥락, 아카이브 이미지 |
| 실물 확인 정보 | 이 매장 및 인근 매장 재고, 착용 이미지, 지난 구매 사이즈 이력 |
| 액션 | 아카이브 저장, 어드바이저 호출, 온라인 상세 이동 |

제작 배경 영역이 이 화면의 핵심이다. 고객이 매장을 나가서 검색할 이유를 제거하는 것은 가격 정보가 아니라 다른 곳에서 얻을 수 없는 브랜드 고유의 맥락이다.

### F2. 방문 리포트 (P0)

매장 이탈이 감지되면 그날의 방문 기록이 정리되어 전달된다. 계정 연결은 이 시점에 유도한다.

- 살펴본 제품 목록과 순서
- AI가 정리한 관심 경향
    - 예시: 블랙 계열, 노트북 수납 가능, 경량 소재 제품을 중심으로 살펴봄
- 저장한 제품을 이어서 볼 수 있는 링크
- 계정 연결 시 기록이 영구 보관됨을 안내

이탈 감지는 마지막 스캔 이후 일정 시간 경과를 기준으로 한다. 위치 기반 지오펜싱은 사용하지 않는다.

### F3. 아카이브 · 후속 접점 (P1)

저장된 제품이 잊히지 않도록 후속 트리거를 운영한다. 모든 알림은 가격이 아닌 제품 상태와 신규 정보를 근거로 한다.

| 트리거 | 발송 내용 |
| --- | --- |
| 재입고 | 품절이었던 사이즈 또는 컬러 입고 안내 |
| 신규 컬러웨이 | 저장 제품의 새 컬러 출시 |
| 매장 재방문 감지 | 이전에 저장한 제품이 현재 매장에 있음을 안내 |
| 어드바이저 준비 | 방문 예약 시 저장 제품을 미리 준비해두었음을 안내 |

### F4. 팝업 패스포트 (P1)

팝업 입구에서 QR을 스캔하면 로그인 없이 디지털 패스포트가 발급된다. 헤리티지 존, 소재 존, 스타일링 존, 제품 존을 체험할 때마다 기록이 누적된다.

- 존별 스캔 시 해당 존의 콘텐츠와 관련 제품을 함께 제공
- 각 존에서 관심 제품을 아카이브에 저장 가능
- 관람 종료 시 개인별 리캡 생성
    - 예시: 이번 팝업에서 트래블 컬렉션과 수납 중심 제품에 가장 오래 머물렀음

**보상 설계**

스탬프 수집이 카페 쿠폰처럼 읽히지 않도록 여권 은유를 유지한다. 보상은 할인이 아니라 접근 권한이다.

| 단계 | 보상 |
| --- | --- |
| 사전 등록 | 전용 시간대 우선 입장 |
| 존 3곳 방문 | 팝업 한정 아카이브 콘텐츠 열람 |
| 존 전체 방문 | 신제품 선공개 알림 구독 |
| 구매 이력 보유 | 다음 팝업 및 브랜드 행사 초대 후보 등록 |

**철수 이후**

패스포트는 삭제되지 않고 아카이브로 전환된다. 방문 기록, 저장 제품, 리캡이 남고 다음 팝업 알림 구독 상태가 유지된다. 팝업 운영비의 성격이 일회성 지출에서 고객 명단 확보 비용으로 전환된다.

### F5. 상담 연결 (P2)

고객이 동의한 경우에 한해 어드바이저가 관심 제품과 선택 기준을 확인할 수 있다.

- 고객 화면에서 공유 범위를 직접 선택
- 어드바이저 단말은 QR 스캔으로 열람, 체류 시간 동안만 유효
- 상담 메모가 고객 타임라인에 저장되어 귀가 후에도 확인 가능
- 세션 종료 시 권한 자동 만료

고객이 취향을 처음부터 다시 설명할 필요가 없어지고, 매장 상담 내용이 온라인에 남는다.

### F6. 운영자 대시보드 (P2)

| 지표 | 설명 |
| --- | --- |
| 제품별 스캔 수 | 관심을 받은 제품 순위 |
| 스캔 대비 구매 전환율 | 관심은 높으나 팔리지 않는 제품 식별 |
| 관심에서 구매까지의 기간 | 카테고리별 의사결정 소요 시간 |
| 매대별 스캔 분포 | 진열 위치와 관심도의 상관관계 |
| 팝업 존별 체류 및 저장 | 존 구성 효율 평가 |

## 6. AI의 역할

기능 장식이 아니라 문제 해결의 핵심으로 작동하는 지점을 명시한다.

| 기능 | AI가 하는 일 |
| --- | --- |
| 방문 리포트 | 스캔한 제품군의 공통 속성을 추출해 관심 경향을 문장으로 정리 |
| 팝업 리캡 | 존별 행동과 저장 제품을 종합해 개인별 요약 생성 |
| 선택 기준 정리 | 저장 제품 간 사양 차이를 고객이 실제로 살펴본 기준에 맞춰 재구성 |
| 아카이브 큐레이션 | 관심 경향에 맞는 브랜드 아카이브 이미지와 스타일링 컷을 선별 제시 |
| 어드바이저 브리핑 | 관심 제품과 미확인 정보를 응대 직전 요약 |

아카이브 큐레이션은 이미지를 새로 생성하지 않고 브랜드가 보유한 캠페인 자산에서 선별한다. 생성 이미지가 브랜드 톤과 어긋날 위험을 피하기 위한 결정이다.

## 7. 사용자 플로우

**메인 시나리오**

```
매장 입장
  → 매대 태그 스캔 (로그인 없음)
  → 제품 정보 + 제작 배경 확인
  → 아카이브 저장
  → 다른 제품 2개 추가 스캔
  → 매장 이탈
  → 방문 리포트 수신
  → 계정 연결
  → 며칠 후 재입고 알림 수신
  → 매장 예약 또는 온라인 구매
```

**팝업 시나리오**

```
사전 등록 (우선 입장 확보)
  → 입구 QR 스캔, 패스포트 발급
  → 존별 스캔 및 관심 제품 저장
  → 관람 종료, 리캡 수신
  → 팝업 철수 후 패스포트 아카이브 전환
  → 신제품 선공개 알림
  → 다음 팝업 초대
```

- 카메라, 센서 기반 자동 인식
- 스캔하지 않은 제품에 대한 관심 추정

## 10. 개발 범위

### 해커톤 MVP

프론트엔드 중심으로 구현 가능하며 하드웨어가 필요하지 않다. QR은 종이 출력으로 대체한다.

**모바일 웹 5개 화면**

1. 스캔 결과 — 제품 정보, 제작 배경, 재고, 저장 버튼
2. 개인 아카이브 — 저장 목록, 관심 경향 요약
3. 방문 리포트 — 오늘 살펴본 제품 정리, 계정 연결 유도
4. 팝업 패스포트 — 존별 진행 상태, 다음 단계 안내
5. 팝업 리캡 — 개인별 요약, 저장 제품, 후속 연결

**PC 웹 1개 화면**

1. 운영자 대시보드 — 제품별 스캔 수, 전환율, 매대별 분포

### 범위 외

- 실제 결제 연동
- NFC 하드웨어 태그 제작 (QR로 대체)
- 어드바이저 단말 네이티브 앱
- 실시간 재고 시스템 연동 (더미 데이터 사용)

| 스캔 후 다른 경로 검색 | 가격이 아닌 브랜드 고유 콘텐츠로 체류 유도. 제작 배경과 아카이브는 타 채널에서 얻을 수 없다 |
| 기존 QR과의 차별성 의문 | 기존 QR은 상세 페이지 이동으로 끝난다. ENTRY는 미구매 기록을 누적하고 재접근 루프를 만든다 |
| 팝업 패스포트 어뷰징 | 시간 기반 회전 코드, 존별 계정당 1회 제한, 스캔 간 최소 시간 간격 검증 |
| 개인정보 우려 | 익명 단계 무수집, 능동 스캔만 기록, 상담 권한 자동 만료 |
| 럭셔리 톤 훼손 | 할인 및 가격 비교 요소 전면 배제, 보상은 접근 권한으로 한정 |
