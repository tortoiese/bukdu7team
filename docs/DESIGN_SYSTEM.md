UI 코드를 작성하기 전에 이 문서를 읽는다. 여기 없는 색·폰트·간격을 새로 만들지 않는다.

## 1. 디자인 컨셉

**"발급 창구"** — 럭셔리 팝업스토어의 입구에서 여권을 발급받는 경험.

카페 스탬프 카드가 아니라 **출입국 관리 문서**다. 이 구분이 흐려지는 순간 럭셔리 톤이 무너진다. 그래서 시각 언어는 세 가지 재료에서만 가져온다.

1. **여권 내지** — 미세 패턴(길로슈), 얇은 괘선, 데이터면 그리드, 여백
2. **검인 도장** — 잉크가 번지고 각도가 틀어진 스탬프, 겹침(multiply)
3. **기계판독영역(MRZ)** — 등폭 대문자, `<` 채움 문자, 하단 고정 밴드

럭셔리는 금박과 화려함으로 오지 않는다. **여백, 얇은 선, 절제된 타이포, 그리고 정확한 정렬**로 온다. 화면당 강조는 하나만.

### 피해야 할 기본값
- 검정 배경 + 금색 **그라디언트** + serif 대문자 = "럭셔리 템플릿". 쓰지 않는다 — 2장의 다크 팔레트는 그라디언트 없는 단색 골드 액센트 + 기존 mono/Archivo 타이포를 그대로 쓴다는 점에서 이 클리셰와 구분한다
- 크림색 배경 + 큰 세리프 + 테라코타 액센트 = AI 기본값. 쓰지 않는다
- 카드마다 그림자, 둥근 모서리 12px, 보라색 그라디언트 버튼 — 전부 금지

## 2. 컬러 토큰

`web/src/styles/tokens.css`에 CSS 변수로 단일 정의. Tailwind v4 `@theme`에 매핑해서 사용한다.

```css
:root {
  /* 기본면 — 여권 표지(다크). 2026-08-20 팀 결정: 피그마 시안(전 화면 목록은 3장 참조) 참조로
     다크 패스포트 톤으로 전환. ink-900은 항상 "가장 어두운" 역할을 유지하고,
     ink-700/graphite/hairline/bone-100은 다크 배경 위 텍스트·괘선 역할로 뒤집혔다.
     bone-050만 원래의 밝은 크림톤을 유지해 "내지" 스코프(.theme-light)의 배경 전용으로 남는다. */
  --ink-900:  #1C140F;   /* 가장 어두운 톤. 화면 기본 배경 + MRZ 밴드 */
  --ink-700:  #EDE4D6;   /* 다크 배경 위 최상위 텍스트(밝은 크림) */
  --graphite: #A89478;   /* 다크 배경 위 보조 텍스트·라벨 */
  --hairline: #3A2E22;   /* 다크 배경 위 괘선 1px */
  --bone-100: #2B2019;   /* 다크 배경 위 살짝 밝은 표면(캐릭터 말풍선 등) */
  --bone-050: #F0E6D2;   /* 밝은 내지 크림 — 항상 밝음. .theme-light 스코프의 배경 전용 */

  /* 액센트 — 면적 최소, 화면당 1~2회 */
  --stamp:    #9C6640;   /* 입국 도장 잉크. 웜 테라코타. 승인·완료 */
  --seal:     #A8332A;   /* 검인 적색. 미해결·주의. 전체 화면 1개 이하 */
  --cognac:   #C89B5C;   /* 브랜드 액센트. CTA·활성 상태·진행 게이지 — 골드(그라디언트 아님, 단색) */
}

/* 라이트 스코프 — 패스포트(P2) 실물 문서 패널, D1/D2 운영 대시보드, /dev 도구에서 원래(밝은)
   팔레트로 되돌린다. 커스텀 프로퍼티는 사용된 DOM 위치 기준으로 재계산되므로 이 클래스로 감싼
   하위 트리 안에서만 옛 라이트 팔레트가 적용된다. Tailwind 유틸리티(bg-ink-900 등)가 참조하는
   --color-* 별칭은 :root에서만 계산되고 그대로 상속되므로 별도로 다시 덮어써야 한다 — 자세한
   이유는 web/src/styles/tokens.css의 주석 참조.
.theme-light {
  --ink-900: #2B2015;
  --ink-700: #2B2B24;
  --graphite: #6B6A60;
  --hairline: #C9C4B6;
  --bone-100: #E6E2D7;
  color: var(--ink-700);
  --color-ink-900: var(--ink-900);
  --color-ink-700: var(--ink-700);
}
*/
```

**사용 배분** — 배경/텍스트가 화면의 92%, 액센트가 8% 이하.
`--seal`은 "미해결 요인", "재고 없음"에만. 에러 메시지에 남용하지 않는다.

**다크/라이트는 사용자가 고르는 "모드"가 아니다.** 토글이나 설정은 여전히 만들지 않는다 — 이 규칙은
유지된다. 대신 화면 성격에 따라 고정된 스코프를 쓴다: P1/P3~P8·D1·D2는 다크(`:root` 기본값),
패스포트(P2)의 실물 문서 패널과 D1/D2·`/dev` 도구는 `.theme-light`로 감싸 원래의 밝은 "종이" 톤을
유지한다. 어느 화면이 어느 스코프인지는 새 화면을 추가할 때마다 판단해서 고정하고, 임의로 섞지 않는다.

## 3. 타이포그래피

`@fontsource` npm 패키지로 로컬 호스팅한다. Google Fonts CDN을 직접 링크하지 않는다.

```
npm i @fontsource/archivo @fontsource/courier-prime @fontsource/noto-sans-kr
```

| 역할 | 폰트 | 사용처 |
|---|---|---|
| Display | **Archivo** 600/700, letter-spacing `-0.02em`, 대문자 아님 | 화면 제목, 제품명 |
| Body | **Archivo** 400/500 | 본문, 설명 |
| Utility / MRZ | **Courier Prime** 400/700, `letter-spacing 0.08em`, 대문자 | 라벨, 코드, 날짜, MRZ 밴드, 지표 숫자 |
| CJK | **Noto Sans KR** | 위 세 폰트 뒤 fallback으로 항상 붙인다 |

```css
--font-display: 'Archivo', 'Noto Sans KR', sans-serif;
--font-body:    'Archivo', 'Noto Sans KR', sans-serif;
--font-mono:    'Courier Prime', 'Noto Sans KR', monospace;
```

**타입 스케일** (모바일 402px 기준)

| 토큰 | 크기/행간 | 용도 |
|---|---|---|
| `display-l` | 30 / 34 | 화면 최상단 제목 (화면당 1회) |
| `display-m` | 22 / 28 | 섹션 제목, 제품명 |
| `body` | 15 / 23 | 본문 |
| `body-s` | 13 / 20 | 보조 설명 |
| `label` | 11 / 14, mono, uppercase, `+0.1em` | 필드 라벨, 상태 |
| `mrz` | 12 / 16, mono, uppercase, `+0.14em` | MRZ 밴드 |

규칙: **라벨은 전부 mono 대문자, 값은 Archivo.** 이 대비가 문서 느낌을 만든다.
한국어 라벨에는 `uppercase`가 적용되지 않으므로 `letter-spacing`만 유지한다.

## 4. 레이아웃 · 간격

- 간격 단위는 4px 배수. `--sp-1:4 / 2:8 / 3:12 / 4:16 / 6:24 / 8:32 / 12:48`
- 모바일 좌우 여백 **20px 고정**
- **border-radius 0**. 예외는 캐릭터 아바타(원형)와 진행 게이지(2px)뿐
- **box-shadow 금지.** 층 구분은 `1px solid var(--hairline)`와 배경 명도차로만
- 섹션 구분은 하드라인 1px. 카드로 감싸지 않는다
- 데이터면(P2 여권 상단)은 2열 라벨/값 그리드, 라벨 열 고정폭 96px

## 5. 시그니처 요소 (이 서비스를 기억시키는 것)

### 5.1 MRZ 상태 밴드
모바일 화면 **하단 고정 밴드**. 현재 상태를 여권 기계판독영역 형식으로 표시.

```
ENTRY<<SEOUL<SEONGSU<<ZONE03<<<<<<<<<<<<<<
SAVED07<<INTENT<COLOR<<MKT<KR>HK<<<<<<<<<<
```

- 2행, `--ink-900` 배경, `--bone-050` 텍스트, mono 12px
- 2026-08-20~: 화면 기본 배경도 `--ink-900`이 되어 밴드와 명도가 같아지므로, 상단에 `--hairline` 1px 보더로 층을 구분한다
- 값이 바뀔 때 해당 글자만 **글자 단위로 스크램블 후 확정**되는 마이크로 애니메이션
- 국경 이전(P4)에서 `MKT<KR>HK`로 바뀌는 순간이 데모의 시각적 클라이맥스. 이 전환은 1.2초에 걸쳐 천천히 진행
- 탭하면 접힌다. 실제 정보를 담아야 하고, 장식용 난수를 채우지 않는다

### 5.2 스탬프
구역 방문·저장 완료 시 찍히는 도장.

- SVG, `mix-blend-mode: multiply`, 불투명도 0.85
- 각 스탬프마다 `--rot` CSS 변수로 -7deg~+7deg 랜덤(단, 세션 내 고정 — 리렌더마다 바뀌면 안 됨)
- 찍히는 모션: `scale(1.6) → 1.0` 180ms `cubic-bezier(.2,.9,.2,1)` + 잉크 번짐용 blur 2px→0
- 미방문 구역은 **점선 사각형 + 회색 코드만**. 물음표나 자물쇠 아이콘 금지
- `multiply` 블렌드는 밝은 종이 위에서만 잉크처럼 보인다. 다크 화면(`:root` 기본) 위에 직접 찍을 때는 도장 뒤에 작은 `--bone-050` 원형 패치를 둬 밝은 표면을 만들어준다(예: P1 SAVED 도장)

### 5.3 길로슈 배경
여권 내지 미세 패턴. SVG `<pattern>` 또는 반복 배경, 불투명도 0.04 이하. 텍스트 가독성을 해치면 즉시 낮춘다. 이미지 파일 대신 코드로 생성한다.

## 6. 컴포넌트 규격

| 컴포넌트 | 규격 |
|---|---|
| 기본 버튼 | 높이 52px, 전폭, `--cognac` 배경 + `--ink-900` 텍스트, radius 0, 라벨은 mono 대문자 13px |
| 보조 버튼 | 높이 52px, 투명 배경 + 1px `--ink-700` 보더 |
| 필드 라벨 | mono 11px `--graphite`, 값과 4px 간격 |
| 재고 상태 | 텍스트 + 좌측 4px 바. 재고있음 `--stamp` / 이동가능 `--cognac` / 없음 `--seal` |
| 캐릭터 말풍선 | 좌측 40px 원형 아바타 + 우측 텍스트, 꼬리 없음, 배경 `--bone-100` |
| 진행 게이지 | 높이 2px, 트랙 `--hairline`, 채움 `--cognac` |
| 로딩 | 스피너 금지. mono 텍스트 `PROCESSING<<<` 의 `<` 개수가 늘어나는 방식 |
| 토스트 | 하단 MRZ 밴드 바로 위, 2행 mono, 2.4초 |

아이콘은 최소화한다. 필요하면 1.25px stroke의 라인 아이콘만, 채워진 아이콘 금지.

## 7. 모션

| 상황 | 규격 |
|---|---|
| 화면 진입 | 상단→하단 순차 페이드업, 요소당 40ms 지연, 총 320ms 이내 |
| 스탬프 | 5.2 참조 |
| MRZ 값 변경 | 글자 스크램블 240ms |
| 국경 이전 전환 | 저장 카드가 좌→우로 12px 이동하며 시장 코드/통화/재고가 교체. 1.2초 |
| 페이지 전환 | 크로스페이드 160ms. 슬라이드·스케일 전환 금지 |

`@media (prefers-reduced-motion: reduce)` 에서 모든 변환을 제거하고 즉시 최종 상태로 렌더한다. 스탬프도 회전만 남기고 애니메이션 없이 표시.

## 8. 카피 규칙

- 문장형, 평서문, 마침표 있음. 감탄사·이모지 금지
- 버튼은 결과를 말한다: "패스포트에 저장" (O) / "저장하기" "확인" (X)
- AI 결과에 근거를 붙인다: "세 번 확인하셨습니다" 처럼 관측된 행동을 명시
- 금지 어휘: 할인, 특가, 혜택가, 지금만, 놓치지 마세요, 추천 상품
- 사용 어휘: 발급, 기록, 검인, 열람 권한, 이전, 미해결 요인, 본국
- 빈 상태는 행동을 안내한다: "아직 검인이 없습니다. 구역 입구의 태그를 스캔하세요."
- 실패는 사과하지 않고 원인과 다음 행동을 말한다: "재고를 불러오지 못했습니다. 다시 시도하거나 매장 직원을 호출하세요."

## 9. D1/D2 (운영자 화면)

고객 화면과 **의도적으로 다른 밀도**를 갖는다. 여권 은유를 적용하지 않는다.

- 배경 `--bone-050`, 12열 그리드, 1440px 기준
- 지표 숫자는 mono, 라벨은 mono 11px
- 차트는 색 2개(`--ink-700`, `--cognac`)로만. 다색 팔레트·범례 남용 금지
- 그래프 라이브러리는 Recharts 하나만 사용

## 10. 접근성 최저선

- 본문 대비 4.5:1 이상. `--graphite` on `--bone-050`은 통과하지만 13px 이하에서는 `--ink-700` 사용
- 키보드 포커스 링: `outline: 2px solid var(--stamp); outline-offset: 2px`. 절대 `outline:none`으로 지우지 않는다
- 터치 타겟 최소 44×44
- MRZ 밴드는 장식이므로 스크린리더에서 `aria-hidden`, 동일 정보를 접근 가능한 텍스트로 별도 제공
